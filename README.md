# Customer Churn Analysis & Revenue Impact 

## 📌 Project Overview

This project analyzes customer churn using Python, SQL, SQLite, Pandas, NumPy, Matplotlib and Seaborn.

The objective is to identify high-risk customer segments, understand churn patterns, analyze revenue, and generate actionable business insights that can support customer retention strategies.

## 🎯 Business Problem

In the competitive OTT industry, retaining existing customers is critical.

This project analyzes customer demographics, subscription plans, revenue and customer behavior to understand:

- Who is more likely to churn?
- Which subscription plans have higher churn?
- Which states generate the most revenue?
- Which customer segments are at higher risk?
- What factors may be associated with customer churn?
